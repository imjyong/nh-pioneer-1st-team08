## 해석과 주의

- 두 묶음 구분은 5년 내내 유지. 갈림 점수를 "공급망 묶음 − 홍콩·중국 묶음"으로 정의할 근거가 된다
- 다만 항셍테크는 항셍·H주와 0.93~0.99라, 홍콩 "기술주"만의 움직임이라기보다 홍콩·중국 시장 전체 요인에 가깝다
- 선행 상관은 모두 작고 음수. 통제 없이 본 단순 상관이라 아직 신호라고 할 수 없다
- 전체 기간으로 묶은 탐색이다. 전략에서는 학습 구간만으로 묶음을 정하고 다음 구간에 적용한다(워크포워드)

**2묶음 군집, 구성별 + 부트스트랩(거래일 재표집 1,000회)**

| 구성 | 결과 | 같은 2묶음 비율 |
| --- | --- | ---: |
| 아시아만, 종가→종가 | {대만, 닛케이} / {항셍테크, 항셍, H주} | 100.0% |
| 아시아만, 장중 | 같음 | 100.0% |
| 아시아만, 갭 | 같음 | 99.9% |
| 아시아 + 미국 D-1 | {대만, 닛케이, 엔비디아, QQQ} / {홍콩 3개} | 99.8% |

- 미국을 빼도 두 묶음은 그대로. 미국이 대만·일본을 끌어당겨 만든 묶음이 아니다

**재실행 (공통 관측일만 사용)**
- 다섯 지수 공통 관측일 1,093일. 결과 묶음은 같음. 같은 2묶음 비율: 종가→종가·장중 100%(날짜 iid, 5일 블록 모두), 갭 99.7%/99.8%, 아시아+미국 99.8%/99.9%
- 3033 시가 이상일(시가 = 직전 종가이고 항셍 갭 0.1% 초과) 74일. 빼고 다시 해도(n=1,031) 같은 묶음 100%
- 대만 시가 = 직전 종가인 날 7일, 닛케이·항셍·H주 0일
- 갭·장중과 미국 D-1 상관(공통 표본): 대만 0.61/0.29, 닛케이 0.63/0.23, 항셍테크 0.48/−0.04, 항셍 0.45/−0.05, H주 0.43/−0.04

**항셍테크 고유 성분** (탐색용, 전체 기간 β)
- 항셍테크 장중 = 1.53 × 항셍 장중 + 잔차. 잔차 표준편차는 항셍테크의 45%
- 잔차와 대만·닛케이 장중 상관은 0.04, 0.06이다. 그래서 본선 홍콩 요인은 항셍과 H주 평균으로 바꾸고, 3033과 기술주 잔차는 민감도 분석으로 돌렸다
