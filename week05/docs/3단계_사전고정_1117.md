# 3단계 사전 고정: 갈림 점수와 회귀식 (11/17, 회귀 결과를 보기 전에 작성)

## 데이터

- 야후 일봉 `auto_adjust=True`, 현지 통화 로그수익률, 2021-11 ~ 2026-11
- 아시아: 대만 `^TWII`, 닛케이 `^N225`, 항셍테크 ETF `3033.HK`, 항셍 `^HSI`, H주 `^HSCE`
- 미국: 엔비디아 `NVDA`, 나스닥100 ETF `QQQ`
- 순서: 미국 D-1 정규장 → 아시아 D → 미국 D 정규장. 미국 D가 휴장이면 그 행은 뺀다. 아시아 D에 다섯 지수 중 하나라도 없으면 신호를 만들지 않는다

## 아시아 수익률 세 종류

- 갭 = log(시가 D / 종가 D-1)
- 장중 = log(종가 D / 시가 D)
- 종가→종가 = 갭 + 장중

## 표준화

- z = 수익률 ÷ 직전 60거래일 같은 종류 수익률의 표준편차 (D 당일 값은 표준편차 계산에 넣지 않음)

## 요인과 갈림 점수 (본선은 장중 기준)

- 공급망 요인 = 평균(z 대만, z 닛케이)
- 홍콩 요인 = 평균(z 항셍테크, z 항셍, z H주)
- 아시아 공통 요인 = 평균(다섯 지수 z)
- **갈림 점수 = 공급망 요인 − 홍콩 요인**
- 비교용: 같은 식을 종가→종가, 갭 기준으로도 계산
- 보조: 항셍테크 고유 성분 = z 항셍테크 − β × z 항셍 (β는 학습 구간 안에서만 추정)

## 예측 대상 (미국 D 정규장)

- 방향: 엔비디아, QQQ 각각 log(종가 D / 시가 D)
- 변동성: 같은 수익률의 절댓값

## 회귀식

```
미국 D 시가→종가 = a + b1·갈림 점수 + b2·미국 D-1 종가→종가 + b3·아시아 공통 요인 + e
|미국 D 시가→종가| = a + b1·|갈림 점수| + b2·|미국 D-1 종가→종가| + b3·|아시아 공통 요인| + e
```

- 표준오차: Newey-West(HAC), 시차 5일
- 관심 계수: b1

## 검정 묶음 (다중검정 보정 대상)

- 수익률 종류 3(장중, 종가→종가, 갭) × 대상 2(엔비디아, QQQ) × 문제 2(방향, 변동성) = 12개
- Benjamini-Hochberg, FDR 10%

## 검증

1. 전체 기간 회귀 (설명용)
2. 날짜 블록 순열 검정: 갈림 점수 시계열을 날짜 단위로 원형 이동해 b1의 우연 분포 1,000회
3. 워크포워드: 처음 2년으로 학습 → 다음 3개월 예측 → 3개월씩 밀며 반복. β·표준편차는 각 학습 구간 안에서만 계산. 갈림 점수를 넣은 모델과 뺀 모델의 표본 외 성과 비교
4. 사례: 젠슨 황 사임 이후 거래일은 학습에서 빼고 마지막에 따로 본다

## 다음 단계로 가는 기준 (미리 정함)

- 장중 기준 갈림 점수의 b1이 BH 보정 뒤에도 유의하고, 워크포워드에서 갈림 점수를 넣은 모델이 뺀 모델보다 나으면 ML과 매매 규칙 단계로 간다
- 방향은 안 되고 변동성만 되면 목표를 변동성 예측(진입 여부, 포지션 크기)으로 바꾼다
- 둘 다 안 되면 "아시아 갈림은 미국 D에 추가 정보가 없다"를 결과로 쓰고, 30분·60분 단위 분석으로 넘어갈지 따로 판단한다

**홍콩 요인 (3033 시가 문제)**
- `3033.HK`는 시가가 직전 종가와 같은 날이 103일이고, 그중 74일은 같은 날 항셍 갭이 0.1%를 넘는다. 시가가 부정확할 가능성이 커서 장중 수익률에 바로 쓰지 않는다
- **본선 홍콩 요인 = 평균(z 항셍 장중, z H주 장중)**
- 3033 포함 버전(시가 이상일 제외)은 민감도 분석으로 돌린다. 항셍테크 고유 성분도 민감도 분석

**아시아 공통 요인**
- 공통 요인 = (공급망 요인 + 홍콩 요인) / 2. 지역별로 같은 무게로 통제한다

**회귀 이름과 형태**
- "방향 회귀"를 **"수익률 예측 회귀"(연속형 OLS)**로 부른다. 부호(오를지 내릴지) 예측은 다음 단계 ML(로지스틱 회귀)에서 따로 한다

**항셍테크 고유 성분 (보조)**
- 학습 구간에서 z항셍테크 = α + β·z항셍 + ε를 적합하고, 시험 구간에서 α와 β를 모두 빼서 잔차를 만든다

**순열 검정**
- 갈림 점수만 움직이지 않고, **아시아 특징 묶음 전체(갈림 점수, 공통 요인, 그 절댓값)를 함께** 날짜 단위로 원형 이동한다. 미국 쪽(목표, 미국 D-1)은 그대로 둔다
- 이동 폭은 20거래일 이상 무작위, 1,000회
- 양측 p값 = (1 + |b1*| ≥ |b1|인 횟수) / (1 + 1,000)

**워크포워드**
- 확장형(expanding): 처음 504거래일(약 2년)로 학습 → 다음 63거래일(약 3개월) 시험 → 학습 구간에 그 63일을 더해 다시 학습, 끝까지 반복
- 표준화용 60일 표준편차는 시험 기간에도 그날 이전 값만으로 하루씩 갱신한다
- 주 지표: 수익률 회귀는 **표본 외 R²** = 1 − Σ(오차², 갈림 포함 모델) ÷ Σ(오차², 갈림 뺀 모델). 변동성 회귀는 **MAE**를 같은 방식으로 비교
- "낫다" 기준: 표본 외 R² > 0 (변동성은 MAE가 더 작음). 같으면 낫지 않은 것으로 본다
