# 4단계 사전 고정: 아시아 오전장 갈림 → 오후 MNQ (11/17, 결과 보기 전 작성)

## 지위

- 일봉 분석(3단계)이 사전 기준을 통과하지 못한 뒤 추가한 탐색적 분석이다. 일봉 결론은 바꾸지 않는다
- 결과가 좋아도 "오전 세션에서 추가 탐색 신호가 보였다"로만 말한다

## 점심 봉 확인 (최근 60일, 30분봉과 60분봉 시가·종가 대조, `check_lunch_bars.py`)

최근 60일에서만 확인했고, 그 이전 기간도 같은 구조라고 가정한다(거래소 세션이 바뀌었다면 틀릴 수 있음)

| 시장 | 결과 | 오전장 마지막 가격 |
| --- | --- | --- |
| 닛케이 | 09·10·11시 봉은 30분 두 개. 11시 봉에 11:00·11:30 행 포함. 12시 봉은 실제 12:30 30분 하나 | **11:00 봉 종가** |
| 대만 가권 | 10~13시 봉은 30분 두 개, 14시 봉은 30분 하나 | 13:00까지 확정되는 **12:00 봉 종가** |
| 항셍·H주 | 10:30·11:30·12:30 봉은 30분 두 개(12:30 봉에 13:00 행 포함). 13:30 봉은 실제 14:00 30분 하나 | **12:30 봉 종가** |

다음 봉 시가(오후장 재개 가격)는 쓰지 않는다. 60일 동안 항셍 10:30 봉 1일, H주 10:30 봉 1일만 예외

## 오전 수익률 (한국 시각, 시장별 오전 세션 대용 구간)

- 일본: 09:00 봉 시가 → 11:00 봉 종가
- 대만: 10:00 봉 시가 → 12:00 봉 종가
- 홍콩: 10:30 봉 시가 → 12:30 봉 종가
- 모두 한국 13:00까지 확정된다. 구간 길이가 달라(2.5~3시간) "같은 시간의 반응"이 아니라 "각 시장 오전 세션의 누적 반응"이다

## 특징

- z = 오전 수익률 ÷ 같은 정의의 직전 60거래일 표준편차 (`shift(1)`, 당일 제외)
- 공급망 = 평균(z 대만, z 닛케이), 홍콩 = 평균(z 항셍, z H주)
- 갈림 = 공급망 − 홍콩, 공통 = (공급망 + 홍콩) / 2
- 네 시장이 모두 있는 공통일만 사용

## 진입과 목표 (`MNQ=F` 60분봉, UTC 정시 봉 시가)

- 진입: 한국 14:00 (UTC 05:00 봉 시가)
- 목표 A: 14:00 → 16:00, 목표 B: 14:00 → 18:00 로그수익률, 그리고 각 절댓값
- 통제: 직전 뉴욕 16:00 → 한국 14:00 `MNQ=F` 수익률(누적 통제 하나만. 최근 1시간 통제는 넣지 않음), 공통 요인
- 롤오버: 분기 셋째 금요일 전 거래일 ~ 이후 2거래일, 아시아 날짜 `d in ROLL`만 제외
- 홀드아웃: 11/12 이후는 사례로만

## 검정 (4개, 한 묶음)

- 2(목표 A·B) × 2(수익률·변동성)
- 수익률: y = a + b1·갈림 + b2·통제 + b3·공통
- 변동성: |y| = a + b1·|갈림| + b2·|통제| + b3·|공통|
- HAC(시차 5) p, BH FDR 10%
- 부트스트랩 (본선): 제한모형(갈림 뺀 모형)을 적합한 뒤 잔차에 10거래일 블록마다 같은 무작위 부호(±1)를 곱해 가짜 y를 만든다. 이 자료로 갈림 포함 모형의 HAC t를 다시 계산한다. 1,000회, 양측 p = (1 + |t*| ≥ |t|) / 1,001. 5일·20일 블록은 민감도
- 워크포워드: 날짜 단위 확장형, 처음 252거래일 학습 → 63일 시험 반복. 수익률은 합친 표본 외 R², 변동성은 합친 MAE 개선. 시험 블록별 개선 여부도 표시. 방향 적중률은 보조

## 중단 기준과 판단

- 공통 완전 관측일(롤·홀드아웃·표준화 60일 제외 후)이 300일 미만이면 중단
- **후속 신호 후보로 인정하는 조건**: 워크포워드 개선(표본 외 R² > 0 또는 MAE 감소) **그리고** 부트스트랩 p < 0.10이 같은 방향. BH 통과만으로는 인정하지 않는다
- 인정되지 않으면 일봉 null 결론으로 정리하고, 매매는 운영 실험으로 분리한다
