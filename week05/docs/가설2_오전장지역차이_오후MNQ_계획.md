# 가설 2 사전 고정: 아시아 오전장 지역 차이와 오후 MNQ (11/17, 결과를 보기 전에 작성)

관련 파일
- 코드: `research/initial/morning.py`, `research/initial/check_lunch_bars.py`

## 배경

- 일봉 분석(가설 1)이 사전 기준을 통과하지 못한 뒤 추가한 탐색적 분석입니다.
- 일봉 결론은 바꾸지 않고, 결과가 좋아도 "오전 세션에서 추가 탐색 신호가 보였다"로만 말합니다.

## 질문

같은 지역 차이를 각 시장의 오전장으로 계산하면, 같은 날 오후 MNQ의 수익률이나 변동성을 예측할 수 있는지 확인합니다.

## 데이터

### 점심 시간 60분봉 구조

- 최근 60일의 30분봉과 60분봉 시가, 종가를 대조해 오전장 마지막 가격이 어느 봉에 있는지 확인
- 그 이전 기간도 같은 구조라고 가정(거래소 세션이 바뀌었다면 틀릴 수 있음)

| 시장 | 60분봉 구조 | 오전장 마지막 가격 |
| --- | --- | --- |
| 닛케이 | 09, 10, 11시 봉은 30분 두 개이고 11시 봉에 11:00, 11:30이 들어감. 12시 봉은 실제로 12:30 30분 하나 | 11:00 봉 종가 |
| 대만 가권 | 10~13시 봉은 30분 두 개, 14시 봉은 30분 하나 | 13:00까지 확정되는 12:00 봉 종가 |
| 항셍, H주 | 10:30, 11:30, 12:30 봉은 30분 두 개(12:30 봉에 13:00 포함). 13:30 봉은 실제로 14:00 30분 하나 | 12:30 봉 종가 |

- 다음 봉 시가(오후장 재개 가격)는 쓰지 않음
- 60일 중 예외: 항셍 10:30 봉 1일, H주 10:30 봉 1일

### 진입과 목표

- `MNQ=F` 60분봉, UTC 정시 봉 시가
- 네 시장이 모두 있는 날만 사용, 11/12 이후는 사례로만 봄
- 월물 교체: 분기 셋째 금요일 전 거래일부터 이후 2거래일까지, 아시아 날짜 기준으로 제외

## 정의

**오전 수익률** (한국 시각)
- 일본: 09:00 봉 시가 → 11:00 봉 종가
- 대만: 10:00 봉 시가 → 12:00 봉 종가
- 홍콩: 10:30 봉 시가 → 12:30 봉 종가
- 모두 한국 13:00까지 확정
  - 구간 길이가 달라(2.5~3시간) 같은 시간의 반응이 아니라 각 시장 오전 세션의 누적 반응

**특징**
- z = 오전 수익률 ÷ 같은 정의의 직전 60거래일 표준편차(당일 제외)
- 공급망 = 평균(z 대만, z 닛케이), 홍콩 = 평균(z 항셍, z H주)
- 지역 차이 = 공급망 − 홍콩, 공통 = (공급망 + 홍콩) / 2

**목표와 통제**
- 진입: 한국 14:00(UTC 05:00 봉 시가)
- 목표: 로그수익률과 각 절댓값
  - A: 14:00 → 16:00
  - B: 14:00 → 18:00
- 통제
  - 직전 뉴욕 16:00 → 한국 14:00 `MNQ=F` 수익률(누적 통제 하나만 쓰고 최근 1시간 통제는 넣지 않음)
  - 공통 요인

## 검정

- 2(목표 A, B) × 2(수익률, 변동성) = 4개를 한 묶음으로 봄
- 회귀
  - 수익률: y = a + b1·지역 차이 + b2·통제 + b3·공통
  - 변동성: |y| = a + b1·|지역 차이| + b2·|통제| + b3·|공통|
- HAC(시차 5) p에 BH FDR 10% 적용
- 본선 부트스트랩
  - 지역 차이를 뺀 제한모형을 적합하고, 잔차에 10거래일 블록마다 같은 무작위 부호(±1)를 곱해 가짜 y 생성
  - 이 자료로 지역 차이 포함 모형의 HAC t를 다시 계산
  - 1,000회, 양측 p = (1 + |t*| ≥ |t|) / 1,001
  - 5일과 20일 블록은 민감도
- 워크포워드: 날짜 단위 확장형으로 처음 252거래일 학습, 63일 시험 반복
  - 수익률은 합친 표본 외 R², 변동성은 합친 MAE 개선
  - 시험 블록별 개선 여부도 표시
  - 방향 적중률은 보조

## 판정 기준

- 공통 완전 관측일(월물 교체, 홀드아웃, 표준화 60일 제외 후)이 300일 미만이면 중단합니다.
- 워크포워드 개선(표본 외 R² > 0 또는 MAE 감소)과 부트스트랩 p < 0.10이 같은 방향으로 나오면 후속 신호 후보로 인정합니다.
  - BH 통과만으로는 인정하지 않음
