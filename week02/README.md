# Week 02. 국내상품 전략 구현: 3년 국채선물 이동평균 교차

## 수행 내용

3년 국채선물 2026년 12월물을 대상으로 5분봉 이동평균 교차 전략을 구현했습니다. 설정값은 8개 버전을 백테스트로 비교해 정했고, 모의계좌에서 장중에 실행했습니다.

- 상품: 3년국채 F 202612 (`A656C000`), KRX
- 전략: 5분봉 SMA 12/36 교차, ATR(14) × 2.5 손절
- 실행 환경: 모의계좌 주문
- 실행일: 2026-10-30
- 실행 결과: 거래 1회, 선물확정손익 −1틱 (수수료 별도)

## 1. 과제 요약

- 시세 조회 (`core/market_data.py`)
  - 과거 분봉 & 일봉 조회
  - 장중 1초마다 최우선 호가 조회
- 진입, 청산 (`strategy.py`, `live.py`)
  - 새 교차가 발생한 봉에서만 진입
  - 손절, 반대 교차, 마감 시 청산
- 위험 관리
  - ATR 손절
  - 하루 최대 6회 진입, 일일 손실 한도 30틱
- 실행 기록: `results/`에 실행 로그(`.log`)와 이벤트 기록(`.jsonl`) 저장
- 결과 분석: [백테스트 8개 버전 비교](#6-1-백테스트), [모의계좌 실행 결과](#6-2-모의계좌-실행)

## 3. 전략과 매매 계획

### 3-1. 대상 상품

10년물보다 거래량이 많은 편이라 주문 체결에 유리한 3년물을 선택했습니다. 그러나 3년물의 경우 가격 변동 폭이 작아 거래 비용이 수익보다 커질 수 있습니다.

- 호가단위(1틱): 0.01, 1계약 기준 10,000원
- 최종거래일: 2026-12-15

### 3-2. 전략 근거

금리는 통화정책 사이클에 따라 며칠 동안 한 방향으로 움직이기도 합니다. 이때 국채선물 가격에는 금리와 반대 방향의 흐름이 나타날 수 있어 추세추종 전략을 선택했습니다.

과제 기간 안에 주문과 체결을 확인할 수 있도록 5분봉을 사용했습니다. 다만 가격이 짧게 등락할 때도 교차 신호가 날 수 있다는 한계가 있습니다.

### 3-3. 매매 규칙

- 진입
  - SMA12가 SMA36을 상향 교차하면 매수, 하향 교차하면 매도
  - 새 교차가 발생한 봉에서만 진입
  - 09:15 ~ 15:00에 끝난 봉만 사용
  - 1계약
- 청산
  - 손절: 진입 시점의 ATR(14) × 2.5를 틱 단위로 올림, 최소 2틱
  - 반대 교차
  - 15:28 마감 청산
- 한도
  - 하루 최대 6회 진입
  - 실현손익과 미실현손익의 합이 −30틱에 도달하면 청산 후 당일 진입 중단
- 일봉 필터
  - 전일 종가가 일봉 SMA20보다 높으면 매수만, 낮으면 매도만 허용
  - 이번 실행에서는 필터를 끄고 신호마다 판정 결과만 기록

### 3-4. 주문 처리

- 시작할 때 포지션이나 미체결 주문이 남아 있으면 실행하지 않습니다.
- 진입 주문은 최우선 호가에 지정가로 냅니다.
  - 10초 안에 체결되지 않으면 취소합니다.
  - 취소 완료를 확인할 때까지 신규 진입은 하지 않습니다.
- 손절, 일일 손실 한도, 반대 교차, 마감 청산은 시장가로 주문합니다.
- 15:33에 포지션과 미체결 주문을 다시 확인한 뒤 종료합니다.

### 3-5. 설정값을 정한 과정

비교 기간이 짧아 최적값으로 단정하지 않고, 모의계좌 실행에 사용할 설정만 골랐습니다. 버전별 결과는 [6-1 표](#6-1-백테스트)에 정리했습니다.

- 과거 5분봉 33거래일(9/9 ~ 10/29)을 IS(in-sample)와 OOS(out-of-sample)로 나눴습니다.
  - 비교 기간(IS) 22일: 8개 설정을 비교해 실행할 설정 선택
  - 확인 기간(OOS) 11일: 선택한 설정만 다시 실행
- 비교 결과
  - 8/24는 거래가 늘고 결과가 가장 나빴으며, 18/54도 더 낫지 않아 **12/36**을 유지했습니다.
  - ATR 배수가 1.5나 2.0일 때 손절이 자주 발생해 **2.5**로 조정했습니다.
  - 손절 폭이 1틱까지 줄어드는 것을 막기 위해 최소 손절 폭을 **2틱**으로 정했습니다.
  - 일봉 필터를 켜면 손실은 줄었지만 거래 수와 비교 기간이 부족해 이번 실행에서는 끄고 판정 결과만 기록했습니다.

## 7. 결과 해석과 한계

### 7-1. 백테스트

`atr_2.5`는 슬리피지 0틱에서는 비교 기간과 확인 기간 모두 이익이었지만, 체결마다 1틱을 적용하면 손실로 바뀌었습니다. 비교 기간의 슬리피지 반영 전 평균 손익은 **거래당 1.03틱으로, 왕복 슬리피지 2틱보다 작았습니다.**

- 백테스트에는 다음 가정을 적용했습니다.
  - 신호가 발생한 다음 봉의 시가에 체결
  - 봉의 고가나 저가가 손절선에 닿으면 청산
  - 체결할 때마다 고정 슬리피지 적용
  - 15:28 마감 청산을 15:25 봉 시가로 계산
- 비교 기간 첫날인 9월 9일은 이전 분봉을 지표 계산에 넣지 않아 오전 신호가 없었습니다.
- 수수료는 반영하지 않았습니다. 그러나 모의계좌 수수료는 편도 3,460원으로 약 0.35틱이며, 왕복으로는 약 0.7틱입니다. 수수료까지 포함하면 손실은 더 커질 것으로 보입니다.

### 7-2. 모의 실행

**거래가 1건뿐이라 전략 성과를 판단하기에는 표본이 부족합니다.** 이번 실행에서는 계획한 규칙이 실제 주문에서 제대로 동작하는지를 확인했습니다.

- **계획대로 동작한 점**: 09:15 이후 이동평균선이 새로 교차한 봉에서만 진입했고, 최우선 호가에 지정가로 주문했습니다. 손절 폭도 진입 시점의 ATR로 계산했습니다.
- **계획과 달랐던 점**: 반대 교차 청산 주문은 시장가 FAK 조건 때문에 거부되어 직접 청산했습니다([8절](#8-오류-제보와-개선사항)).
  - 포지션을 청산하려고 프로그램을 중단하여, 이후 발생한 14:50 매도, 14:55 매수 신호는 실행하지 못했습니다.
  - 장 마감 후 같은 분봉으로 다시 계산한 결과, 프로그램이 실행되는 동안 놓친 신호는 없었습니다.
  - 14:35~14:55 사이에 두 이동평균선이 세 번 엇갈려, 짧은 등락이 이어지면 5분봉 신호도 연달아 나올 수 있음을 확인할 수 있었습니다.
- 실제 청산이 약 3분 늦어졌기 때문에 −1틱을 전략 자체의 손익으로 해석하기는 어렵습니다.
- 일봉 필터가 차단했을 거래도 이 1건뿐이어서 필터 효과는 판단하지 않았습니다.

## 8. 오류 제보와 개선사항

- **오류 1: 시장가 FAK 청산 주문 거부 (`5039`)**
  - 반대 교차에서 낸 청산 주문이 거부됐고, 재시도 로직이 없어 포지션이 남았습니다.
  - 시장가는 FAS만 사용할 수 있지만 API 문서에는 이 제한이 명시되어 있지 않았습니다.
  - 남은 포지션은 직접 청산하고, 시장가 주문의 체결조건을 FAS로 수정했습니다.
  - 오류-문의 채널에 제보했으며, 담당자님의 답변으로 시장가는 FAS만 가능하다는 것을 확인했습니다.

- **오류 2: 모의 서버 응답 지연**
  - 같은 분봉 요청이 07시에는 0.2초, 08:58에는 5초 이상 걸렸습니다.
  - 응답이 올 때까지 실행 루프도 함께 멈추는 문제가 있었습니다.
  - 호가는 3초까지만 기다리고 실패하면 바로 한 번 더 조회하고, 분봉과 주문은 10초까지 기다리도록 대기 시간을 구분했습니다.
  - 봉 마감 시점에 호가 조회가 실패하면 해당 신호를 최대 30초 동안 보류하도록 수정했습니다.

- **오류 3: 분봉 2,000개 요청 시 시간 초과**
  - 한 번에 2,000개를 요청하면 응답 시간이 초과돼 300개씩 나눠 받았습니다.

- **오류 4: 10년물 조회 중 `EGW032` 발생**
  - 백엔드 응답 시간 초과로 10년물 데이터를 받지 못했습니다.
